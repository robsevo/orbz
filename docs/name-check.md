## Trademark

Inconclusive from the web. "ORBS" marks exist for unrelated goods (e.g. Abstract Ice, ODS Products
— [uspto.report](https://uspto.report/TM/97099856), [uspto.report](https://uspto.report/TM/99153085)).
Orbs Network uses "Orbs" for software, which is the real risk in classes 9/42. Before spending on
branding: search [tmsearch.uspto.gov](https://tmsearch.uspto.gov) and CIPO (Canada) for "ORBS" in
classes 9 and 42.

## Recommendation

Keep **Orbs** as the product name and the word for the characters ("your orbs"), and use one
distinctive handle everywhere: **`useorbs`** — free on GitHub, npm and PyPI, and `useorbs.com` /
`useorbs.app` gave no DNS answer. Fallback handle: **`getorbs`** (free on GitHub and npm,
`getorbs.app` no DNS answer). Grab PyPI `orbs` for the kit too, so nobody squats it.
